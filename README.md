# TouhouLittleFriend (Meiling Kung Fu Edition)

This project is identical to [MineGame223/TouhouLittleFriend/tree/yuka_newmode](https://github.com/MineGame223/TouhouLittleFriend/tree/yuka_newmode).

The only modification is for those (including myself!) who want to see more of Hong Meiling's actions. In this version, Meiling has a 1/3 probability of performing KungFu moves instead of falling asleep.
